# A Grant-Indexed Measurement of How ERC-20 Approvals Outlive the Code They Trusted — Artifact

Artifact for the BSS 2026 paper. It reproduces every
figure, table, and headline statistic in the paper from public Ethereum state.

## Contents

```
rpccore.py              Shared JSON-RPC layer: batching, getLogs windowing,
                        token list, EIP-1967 slots, endpoint failover.
collect_scaled.py       Grant sampler: Approval(owner,spender,value) events over
                        12 tokens x 5 age epochs x 4 dispersed windows.
classify_scaled.py      Trust-state classifier: LIVE / MUTATED / PROXY_STABLE /
                        EOA, using code@now, impl@now, and impl@grant-block.
authority.py            Real upgrade-authority resolver for MUTATED proxies
                        (admin slot -> ProxyAdmin.owner(); UUPS owner(); beacon).
realized_verified.py    Verified realized-use scan; requires tx.from == spender.
ttl2.py                 Allowance-TTL counterfactual (all MUTATED grants).
ttl_dangerous.py        Allowance-TTL counterfactual (single-key dangerous subset).
stats.py                Spender-clustered bootstrap CIs.
figures.py              Figures 1-3 (print-safe, TrueType-embedded PDF).
fig4_ttl.py             Figure 4 (TTL curve).
data/                   Derived JSON needed to reproduce all outputs (below).
```

## Derived data included (`data/`)

| file | what it holds |
|---|---|
| `grants_scaled_classified.json` | 54,641 grants with trust-state labels (main input) |
| `authority.json`                | resolved upgrade authority of every MUTATED proxy |
| `realized_verified.json`        | verified realized-use scan results (n=121 cohort) |
| `impl_at_grant.json`            | archival EIP-1967 impl slot at each grant block |
| `spender_info.json`             | per-spender current code / impl / nonce |
| `ttl.json`, `ttl_dangerous.json`| TTL counterfactual outputs |
| `stats_meta.json`               | sample cardinalities (grants/spenders/owners) |

The ~25 MB raw event dumps are omitted for size; they are regenerated by
`collect_scaled.py` against any archival node.

## Before running

Large JSON files are stored gzip-compressed. Decompress them once:

```bash
gunzip data/*.json.gz revision/*.json.gz
```

## Reproduce

```bash
pip install matplotlib requests        # only deps
# statistics (Table I CIs; prints MUTATED/EOA/PROXY_STABLE bootstrap intervals)
python stats.py
# figures 1-4
python figures.py && python fig4_ttl.py
# TTL counterfactual on the dangerous subset (hits public RPC, ~90s)
python ttl_dangerous.py
```

`stats.py`, `figures.py`, and `fig4_ttl.py` run offline from the shipped JSON.
`ttl_dangerous.py` (and the collection/classification/authority scripts) read
live chain state via the public endpoints configured in `rpccore.py`
(`eth.drpc.org`, `rpc.mevblocker.io`, `ethereum-rpc.publicnode.com`); point them
at your own archival node for full end-to-end regeneration.

## Notes

- All inputs are public Ethereum state; the study is entirely passive (no
  transactions are sent).
- MUTATED and EOA shares are lower bounds: only EIP-1967 proxies are detected;
  Diamond/beacon/custom-slot proxies are conservatively counted as LIVE.
- Bootstrap seed is fixed (`random.seed(0)`) for exact CI reproduction.

## Revision (camera-ready) pipeline — `revision/`

The revised paper re-classifies every grant and adds a snapshot of the live
state. All revision scripts read the original grants from `../data/` and write
their outputs next to themselves. Run them from inside `revision/` in this order:

```
snapshot.py      allowance(owner,spender) and balanceOf(owner) for all 24,298
                 grant relations at one fixed snapshot block (26,189,588)
prices.py        Chainlink USD feeds at the same block (descriptions verified)
probes.py        per-spender code/nonce at snapshot, EIP-7702 designator,
                 code at first grant block (+ deployment block), beacon /
                 EIP-1822 / ZeppelinOS slots, Diamond facetAddresses()
impl_now.py      EIP-1967 implementation slot at the snapshot block
nonstd.py        beacon target / Diamond facets() / legacy slot at every grant
                 block and at the snapshot (non-EIP-1967 drift)
final_stats.py   revised classes (Non-proxy, Proxy-stable, Mutated, Code-less,
                 Deployed-later), cluster-bootstrap CIs, standing / funded /
                 exposed by class, unlimited shares, code-less activity split,
                 epoch and token tables; writes grants_revised.json
authority2.py    upgrade authority of EIP-1967 Mutated proxies at the grant
                 block AND at the snapshot, extended resolver
authority3.py    the same for Diamond / beacon / legacy-slot Mutated proxies
authority4.py    the same for proxies upgraded after the original collection
                 (final_stats.py writes the missing list; re-run it afterwards)
gov.py           Safe thresholds / owner counts and timelock delays
ttl3.py sample   TTL counterfactual, random 400 Mutated grants (seed 0)
ttl3.py danger   TTL counterfactual, all grants single-key at grant or now
figs_rev.py      Figures 1-4 of the revised paper
```

Archival reads use `rpc.mevblocker.io` first (public, archival, batch-friendly);
`ethereum-rpc.publicnode.com` no longer serves archival requests without a token.
All outputs used in the paper are included, so `final_stats.py`, `gov.py`
(needs RPC) and `figs_rev.py` reproduce every number and figure.
